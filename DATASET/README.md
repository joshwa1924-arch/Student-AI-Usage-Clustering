# Dataset

This folder contains the dataset used for analysing student AI assistant usage patterns.

The dataset contains information about student sessions with an AI assistant.

### Major Features

- SessionID – Unique session identifier
- StudentLevel – Undergraduate or Postgraduate
- Discipline – Student's field of study
- SessionLengthMin – Time spent using the AI assistant
- TotalPrompts – Number of prompts sent
- TaskType – Purpose of AI usage
- AI_AssistanceLevel – Level of assistance requested
- SatisfactionRating – Student satisfaction after using AI

The dataset was used to identify natural groups of students based on their AI usage behaviour.

Since there were no predefined user labels, unsupervised learning techniques were used.
