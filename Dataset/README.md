# Dataset

This folder contains the car price dataset used for the machine learning prediction project.

The dataset contains 205 car records and 26 attributes covering car brands, technical specifications, physical dimensions, fuel and drive configurations, and market prices.

The target variable is `Price`, which represents the selling price of the car in USD.

### Major Features

- CarName
- enginesize
- horsepower
- stroke
- compressionratio
- peakrpm
- cylindernumber
- enginetype
- fuelsystem
- carlength
- carwidth
- carheight
- wheelbase
- curbweight
- fueltype
- aspiration
- carbody
- drivewheel

The dataset was cleaned and prepared for regression analysis, including correction of brand spelling errors and feature engineering.
