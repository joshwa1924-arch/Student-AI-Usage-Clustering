# Code

This folder contains the Python implementation for the student AI assistant usage clustering project.

### Workflow

1. Load the dataset
2. Check and clean the data
3. Handle missing values
4. Remove duplicate records
5. Convert categorical variables into numerical form
6. Select relevant behavioural features
7. Scale the features
8. Apply Hierarchical Clustering
9. Generate a dendrogram
10. Determine the number of clusters
11. Apply the Elbow Method
12. Evaluate clusters using Silhouette Score
13. Apply K-Means Clustering
14. Visualize clusters using PCA
15. Analyse cluster characteristics
16. Create student behaviour personas

### Clustering Algorithms

- Hierarchical Clustering
- K-Means Clustering

### Evaluation Methods

- Dendrogram
- Elbow Method
- Silhouette Score
- PCA Visualization

The final analysis selected 3 clusters based on the combined results of these methods.
