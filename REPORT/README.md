### Final Clusters

The analysis identified three student behaviour groups:

1. Support-Seekers
   - Short sessions
   - Low number of prompts
   - Highest AI assistance
   - Highest satisfaction

2. Deep Explorers
   - Longest sessions
   - Highest number of prompts
   - Moderate AI assistance
   - Moderate satisfaction

3. Light Users
   - Short sessions
   - Low number of prompts
   - Lowest AI assistance
   - Lowest satisfaction

The final cluster interpretation is based on the average values of session length, prompts, AI assistance level, task type and satisfaction rating.
